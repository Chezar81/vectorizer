# Phased plan

## Milestone 1 — complete

Launch, open raster, trace with VTracer, show original and real SVG, export SVG,
stay responsive, report errors.

## Milestone 2 — complete

Mint-Y-Aqua UI, transparency/background preprocessing, target-color quantize,
result palette + SVG recolor, synchronized side-by-side + split wipe, named
JSON presets, vector PDF (`QPdfWriter`), PNG preview export.

## Milestone 3 — complete

Editable segmentation map, undo/redo with memory budget, retrace from the edited
map, versioned `.vproj` ZIP+JSON projects (no pickle).

## Milestone 4 — complete in this tree

Batch processing (folder/files, presets, collisions, cancel, summary), optional
EPS via Inkscape, native DXF outlines, user-local packaging scripts (venv /
wheel / `.desktop`). AppImage remains planned until an artifact is built and
launched on Mint.
